**项目简介**

moonmeter 是 MoonBit 生态中首个实现中国电能表通信规约 DL/T 645-2007 的协议栈。它提供帧编解码（68H 起始符、BCD 地址域、控制码、双字节长度、累加和校验、16H 结束符）、BCD 电量读数编解码、常用数据标识（DI）定义、电表模拟器与规约一致性校验器，并以库 + CLI 双层交付。项目面向需要接入智能电表、充电桩计费与抄表系统的开发者，把"构造请求 → 模拟应答 → 解码读数 → 一致性校验"的完整抄读闭环搬到纯 MoonBit 代码中，无需硬件即可开发与验证。当前已实现 DL/T 645 主协议全部帧要素与常用数据标识，并规划 DL/T 698.45（面向对象数据交换）作为后续扩展。

**核心功能范围**

- 提供 DL/T 645-2007 帧编解码：起始符、6 字节 BCD 地址域、控制码（含读数据/读后续/写数据/广播校时等 15 个功能码）、数据长度、数据域、累加和校验（CS）与结束符，严格按标准帧格式；
- 提供 BCD 编解码（低字节在前），覆盖地址、时间戳（YY-MM-DD-hh-mm-ss）与电量读数（如 1234.56 kWh 编码为 56 34 12 00）；
- 提供常用数据标识（DI0..DI3）：组合有功总/尖/峰/平/谷电能、电压、电流、功率等；
- 提供读数据请求（0x01）、广播校时（0x05）等命令构造；
- 提供电表模拟器（MeterSim）：注册任意读数并应答读数据请求（0x81 应答帧），可生成合规帧流或带错误（坏校验/坏结束符）的帧流，用于测试与演示；
- 提供规约一致性校验器：将字节流切分为帧并报告 stray_byte / bad_checksum / bad_end / truncated_frame 等结构化诊断，可用于规约一致性测试仪；
- 提供 CLI 四个子命令：parse / validate / read / simulate，离线调试无需硬件；
- 提供 13 项单元测试（帧往返、校验、BCD、命令、模拟器、校验器）、三平台 CI 与 README 示例。

**与现有工具的关系（复用 / 扩展 / 差异）**

- **生态空白**：经 mooncakes.io 检索确认，DL/T 645 / DL/T 698.45 / DLMS/COSEM 电能计量规约在 MoonBit 生态中均无实现；邻近的 Modbus 协议栈（moonbit-modbus）与电表数据审计（moon_meterbalance）不涉及 645 帧格式，定位不同。
- **复用**：数据标识与功能码的定义遵循公开标准（DL/T 645-2007），实现上不依赖第三方协议库；可被上层抄表、计费、充电桩系统作为协议层复用。
- **扩展**：在帧编解码之上新增模拟器与一致性校验器，形成"编码-传输-解码-校验"闭环，这是纯帧库不具备的能力。
- **差异**：moonmeter 回答"一段字节流是否为合法的 DL/T 645 交换，读数是什么"——模拟器与校验器提供可离线复现的验证与分析能力，面向规约一致性测试场景。

**原创与参考说明**

本项目为原创实现，非移植项目。DL/T 645-2007 为公开的国家电力行业标准，帧格式、控制码与数据标识的定义均依据标准文本整理；未使用、未复制任何第三方源代码。许可证 Apache-2.0。
