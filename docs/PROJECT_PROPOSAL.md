# moonmeter 项目申报书

**基本信息**
- 项目名称：moonmeter：DL/T 645 电能表通信协议栈
- 参赛者：Krinph
- GitHub 仓库链接：https://github.com/Krinph/moonmeter
- 项目方向：工具库 / 工业协议基础设施（智能电表、抄表、充电桩计费）
- 是否为移植项目：否（原创项目）
- 当前状态：**MVP 已完成**（版本 0.2.0）

**项目简介**

moonmeter 是 MoonBit 生态中首个实现中国电能表通信规约 DL/T 645-2007 的协议栈。它提供帧编解码（68H 起始符、BCD 地址域、控制码、双字节长度、累加和校验、16H 结束符）、BCD 电量读数编解码、常用数据标识（DI）目录、电表模拟器、错误应答解码与规约一致性校验器，并以库 + CLI + 可运行示例三层交付。项目面向需要接入智能电表、充电桩计费与抄表系统的开发者，把"构造请求 → 模拟应答 → 解码读数 → 格式化 → 一致性校验"的完整抄读闭环搬到纯 MoonBit 代码中，无需硬件即可开发与验证。

**三个完整的使用场景**

1. **无硬件抄表开发**：上层抄表系统在开发/CI 环境中用 `MeterSim` 注册读数并模拟电表应答，验证请求构造与读数解析逻辑，摆脱硬件在环依赖。库调用链：`build_read_request` → `MeterSim::answer_read` → `decode_frame` → `parse_reading` → `decode_energy` → `format_energy`。
2. **规约一致性测试**：设备厂商把协议分析仪抓取的字节流喂给 CLI `validate` 或库 `validate_stream`，自动定位坏校验、错误结束符、非法 BCD、短应答、杂散字节等问题，并汇总错误/警告数，用作出厂检测或回归测试。
3. **充电桩 / 计费数据解析**：把电表上报的 BCD 电量寄存器解码，按 DI 语义标注名称与单位并定点格式化，直接得到可展示、可对账的读数（如 "Total active energy = 1234.56 kWh"）。

**拟实现 / 已实现的核心功能**

- ✅ DL/T 645-2007 帧编解码：起始符、6 字节 BCD 地址域、控制码（读数据/广播校时等 15 个功能码）、数据长度、数据域、累加和校验（CS）与结束符；
- ✅ BCD 编解码（低字节在前），覆盖地址、时间戳与电量读数；12 位地址的合法性校验与字节/字符串互转；
- ✅ 数据标识（DI0..DI3）目录：组合有功总/尖/峰/平/谷电能、电压、电流、功率，附可读名称、单位与小数位；
- ✅ 读数据请求（0x01）、广播校时（0x05）命令构造，以及错误应答（0xC1 类）的结构化解码；
- ✅ 电表模拟器（MeterSim）：注册任意读数并应答读数据请求，可生成合规帧流或带错误（坏校验/坏结束符）的帧流；
- ✅ 规约一致性校验器：字节流切帧并报告 stray_byte / bad_checksum / bad_end / truncated_frame / short_read_reply 等结构化诊断；一步到位 `validate_stream` API 与错误/警告计数；
- ✅ 电量定点格式化：`format_energy` 将 BCD 原始值格式化为 "1234.56" 形式；
- ✅ CLI 四个子命令：parse / validate / read / simulate；
- ✅ 可运行闭环示例 `moon run cmd/roundtrip`；
- ✅ 35 项单元测试、三平台 CI（check/test/格式/接口/smoke）、README 与 mooncakes 包文档。

**与现有工具的关系（复用 / 扩展 / 差异）**

- **生态空白**：经 mooncakes.io 检索确认，DL/T 645 / DL/T 698.45 / DLMS/COSEM 电能计量规约在 MoonBit 生态中均无实现；邻近的 Modbus 协议栈与电表数据审计（moon_meterbalance）不涉及 645 帧格式，定位不同。
- **复用**：数据标识与功能码遵循公开标准（DL/T 645-2007），不依赖第三方协议库；可被上层抄表、计费、充电桩系统作为协议层复用。
- **扩展**：在帧编解码之上新增模拟器、错误解码、一致性校验与电量格式化，形成"编码-传输-解码-校验-展示"闭环，这是纯帧库不具备的能力。
- **差异**：moonmeter 回答"一段字节流是否为合法的 DL/T 645 交换、读数是什么、是否有规约违规"——模拟器、错误解码与校验器提供可离线复现的验证与分析能力。

**原创与参考说明**

本项目为原创实现，非移植项目。DL/T 645-2007 为公开的国家电力行业标准，帧格式、控制码与数据标识的定义均依据标准文本整理；未使用、未复制任何第三方源代码。许可证 Apache-2.0。
